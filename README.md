# Personal Assistant

Консольний персональний помічник для зберігання контактів, днів народження та
нотаток. Дані автоматично зберігаються у файлі `~/.personal_assistant.pkl` і
відновлюються після наступного запуску.

## Встановлення

Потрібен Python 3.10 або новіший:

```bash
python -m venv .venv
source .venv/bin/activate
pip install .
```

Після встановлення застосунок запускається командою:

```bash
assistant
```

Також можна запустити без встановлення: `python main.py`.

## Команди

Для аргументів із пробілами використовуйте подвійні лапки.

| Команда | Приклад |
| --- | --- |
| `add` | `add "Іван Петренко" 0501234567` |
| `change` | `change "Іван Петренко" 0501234567 0671234567` |
| `phone` | `phone "Іван Петренко"` |
| `all` | показати всі контакти |
| `delete` | `delete "Іван Петренко"` |
| `add-birthday` | `add-birthday "Іван Петренко" 25.10.1990` |
| `show-birthday` | `show-birthday "Іван Петренко"` |
| `birthdays` | дні народження найближчих 7 днів |
| `add-note` | `add-note "Покупки" "Молоко та хліб"` |
| `edit-note` | `edit-note "Покупки" "Молоко, хліб та сир"` |
| `delete-note` | `delete-note "Покупки"` |
| `all-notes` | показати всі нотатки |
| `search-notes` | `search-notes "хліб"` |
| `add-tag` | `add-tag "Покупки" важливе` |
| `remove-tag` | `remove-tag "Покупки" важливе` |
| `search-tag` | `search-tag важливе` |
| `help` | показати список команд |
| `close`, `exit` | завершити роботу |

Телефон має містити 10 цифр, а дата народження — бути у форматі
`DD.MM.YYYY`. Некоректні дані не завершують роботу програми.

## Що додано для фінального проєкту

Проєкт розширює попередню домашню роботу з адресною книгою до персонального
помічника. Його призначення — зберігати в одному застосунку контактні дані,
дні народження та текстові нотатки, щоб користувач міг швидко знаходити й
оновлювати потрібну інформацію з командного рядка.

Застосунок побудований на об'єктно-орієнтованій моделі. `AddressBook` керує
контактами, `NoteBook` — нотатками, а `PersonalAssistant` об'єднує ці дві
колекції за допомогою композиції. Поля контактів (`Name`, `Phone`, `Birthday`)
перевіряють дані під час створення, тому неправильний номер телефону або дата
не потрапляють у сховище.

Для нотаток реалізовано:

- заголовок і текст із перевіркою на порожнє значення;
- пошук за заголовком, текстом або частиною слова;
- теги для групування нотаток;
- пошук за тегом;
- редагування та видалення нотаток;
- регістронезалежний пошук заголовків і тегів.

Командний інтерфейс працює в циклі й не завершується через помилкове введення.
Команди з аргументами, що містять пробіли, підтримують подвійні лапки. Команда
`help` показує доступні можливості, а `close` або `exit` завершує роботу.

Під час запуску помічник завантажує попередній стан із
`~/.personal_assistant.pkl`. Перед завершенням роботи контакти й нотатки
серіалізуються через `pickle`, тому дані не втрачаються між сеансами. Старі
файли, у яких зберігалася лише адресна книга, також підтримуються.

Доданий `pyproject.toml` перетворює проєкт на пакет Python. Після команди
`pip install .` застосунок можна запускати з будь-якої директорії командою
`assistant`.

## Документація модулів

### `main.py`

Головний модуль застосунку. Він відповідає за запуск персонального помічника,
читання команд користувача, виклик потрібних обробників і збереження даних.

Основні елементи модуля:

- `PersonalAssistant` — об'єкт, який об'єднує адресну книгу та книгу нотаток;
- `DATA_FILE` — шлях до файлу постійного збереження даних;
- `save_data()` — серіалізує весь стан помічника через `pickle`;
- `load_data()` — завантажує збережені дані або створює порожній помічник;
- `parse_input()` — розбирає введений рядок на назву команди та аргументи;
- `input_error()` — перевіряє кількість аргументів і перетворює помилки
  в зрозумілі повідомлення;
- обробники контактів — `add_contact()`, `change_contact()`,
  `show_phone()`, `delete_contact()`;
- обробники днів народження — `add_birthday()`, `show_birthday()`,
  `show_birthdays()`;
- обробники нотаток — `add_note()`, `edit_note()`, `delete_note()`,
  `search_notes()`, `add_tag()`, `remove_tag()`, `search_tag()`;
- `main()` — нескінченний цикл взаємодії з користувачем.

Цикл продовжується, поки користувач не введе `close`, `exit`, `Ctrl+D` або
`Ctrl+C`. Навіть якщо команда містить неправильні дані, помилка виводиться на
екран, а програма продовжує роботу.

### `contact_book.py`

Модуль предметної області адресної книги. Він містить класи для контактів,
телефонів і днів народження та не залежить від командного інтерфейсу.

#### Класи полів

- `Field` — базовий клас для значень контактних полів;
- `Name` — перевіряє, що ім'я є непорожнім текстом;
- `Phone` — перевіряє, що номер складається рівно з 10 цифр;
- `Birthday` — перевіряє формат `DD.MM.YYYY` і перетворює дату на
  `datetime`.

#### `Record`

Представляє один контакт. Він зберігає ім'я, список телефонів і необов'язковий
день народження.

Клас дозволяє:

- додавати телефон через `add_phone()`;
- знаходити телефон через `find_phone()`;
- змінювати телефон через `edit_phone()`;
- видаляти телефон через `remove_phone()`;
- додавати або змінювати день народження через `add_birthday()`;
- отримувати зручне текстове представлення контакту через `__str__()`.

#### `AddressBook`

Колекція контактів на основі `UserDict`. Вона підтримує пошук і видалення
контактів без урахування регістру. Наприклад, `Іван`, `іван` та `ІВАН`
позначають один і той самий контакт.

Метод `get_upcoming_birthdays()` знаходить дні народження протягом наступних
семи днів і переносить дату привітання з вихідного дня на найближчий понеділок.

### `notes.py`

Модуль для роботи з нотатками. Він відокремлений від адресної книги, але
підключається до неї через `PersonalAssistant`.

#### `Note`

Представляє одну нотатку та містить:

- `title` — унікальний заголовок нотатки;
- `text` — основний текст;
- `tags` — множину тегів.

Клас перевіряє заголовок, текст і теги, а також дозволяє додавати та видаляти
теги. Теги зберігаються в нижньому регістрі, тому пошук не залежить від
регістру.

#### `NoteBook`

Колекція нотаток на основі `UserDict`. Вона відповідає за:

- додавання або оновлення нотатки;
- пошук нотатки за заголовком;
- видалення нотатки;
- пошук за заголовком, текстом або тегом через `search()`;
- пошук усіх нотаток із певним тегом через `by_tag()`.

### `pyproject.toml`

Конфігурація пакування проєкту. У ній вказані назва, версія, опис, мінімальна
версія Python, список модулів і консольна команда `assistant`.

Рядок `assistant = "main:main"` пов'язує команду операційної системи
`assistant` з функцією `main()` у файлі `main.py`.

### `.gitignore`

Містить файли, які не потрібно додавати до Git-репозиторію:

- віртуальне середовище `.venv`;
- кеш Python `__pycache__`;
- скомпільовані файли `.pyc`;
- локальний файл адресної книги `addressbook.pkl`;
- службові файли середовища розробки.
